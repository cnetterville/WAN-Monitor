# WAN Monitor

A macOS menubar application that monitors WAN throughput via SNMP and displays ping status for two network interfaces.

## Features

- **Real-time SNMP monitoring**: Displays download/upload speeds for two WAN interfaces
- **Ping monitoring**: Shows connectivity status to two target hosts
- **Menubar display**: Compact two-line display similar to popular network monitoring tools
- **Configurable**: Easy to customize for your network setup
